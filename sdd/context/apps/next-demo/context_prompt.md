# Context prompt — apps/next-demo

App Next.js 16 privada que prueba el entry `./next` de la lib principal desde su paquete compilado. Antes de tocarla: leer `constitution.md` de este directorio y la de la lib. Correr `pnpm nx run next-demo:e2e` después de cualquier cambio en la lib que afecte navegación, layouts o la frontera server/client.
